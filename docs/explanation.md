# Объяснение проекта EasyProject — Торговая стратегия для акций Сбербанка (SBER)

## 📋 Общее описание

Проект представляет собой систему для **алгоритмической торговли** акциями Сбербанка (SBER) на часовом таймфрейме (1h).

**Что делает этот проект:**
1. **Скачивает исторические данные** с MOEX (Московская биржа) — бесплатно, без ключа
2. **Тестирует стратегию** на истории (бэктест) — сколько бы заработали
3. **Работает в реальном времени** — выдаёт сигналы каждые N секунд
4. **Оптимизирует параметры** — ищет лучшие настройки стратегии

## 🔧 Как устроен каждый файл

### 1. `main.py` — Запуск программы

**Что делает:** выбирает, что делать: скачать данные, запустить бэктест, следить за рынком в реальном времени или подобрать параметры.

```python
MODE = "backtest"  # варианты: download / backtest / realtime / optimize

DATE_FROM = "2022-01-03"   # начало периода
DATE_TO = "2025-06-30"     # конец периода
CASH = 100000              # стартовый капитал
FEES = 0.0005              # комиссия биржи (0.05%)
INTERVAL_SECONDS = 3600    # проверка каждый час (для realtime)

ALL_DATA_FILE = "data/sber_1h_all.csv"   # файл с полной историей
```

**Четыре режима:**
- **download** → скачивает все часовые свечи SBER с MOEX в файл `data/sber_1h_all.csv`
- **backtest** → полный цикл: вырезать период → рассчитать сигналы → запустить VectorBT → показать метрики
- **realtime** → каждые N секунд проверяет сигнал и выводит в консоль
- **optimize** → запускает подбор параметров из `optimize.py`

**Режим backtest** (`run_backtest`) выполняет цикл из 4 шагов:
1. Проверяет, существует ли файл с данными (иначе просит запустить `download`)
2. Вырезает нужный период в `data/sber_<дата>_<дата>.csv`
3. Создаёт стратегию с лучшими параметрами и считает сигналы → `data/signals_<дата>_<дата>.csv`
4. Запускает VectorBT и выводит: доходность, Sharpe Ratio, максимальную просадку, количество сделок

---

### 2. `data_load.py` — Загрузка данных с MOEX

Работает с **бесплатным API Московской биржи**. Не требует регистрации или ключа.

**Две функции:**

| Функция | Что делает |
|---------|------------|
| `download_all_sber_1h()` | Скачивает ВСЕ часовые свечи SBER с 2000 года по сегодня |
| `get_period_for_backtest()` | Вырезает из большого файла только нужный период |

**Как качает данные:**
- Запрашивает по партиям (пагинация) через параметр `start`
- Между запросами ждёт 0.2 секунды (чтобы не нагружать сервер MOEX)
- Склеивает всё в один DataFrame, сортирует по дате, удаляет дубликаты
- Сохраняет в CSV с колонками: `datetime, open, high, low, close, volume`

**`get_period_for_backtest()`** умеет:
- Фильтровать свечи по дате (последний день включается)
- Сохранять вырезку в отдельный файл (если передан `output_file`)
- Возвращать DataFrame и печатать статистику (сколько свечей, какой период)

Если запустить `data_load.py` напрямую — он скачает всю историю и вырежет тестовый период 2024-01-01 … 2024-06-30.

### 3. `strategy.py` — Торговая стратегия (ядро)

Это главный файл. Класс **`SberStrategy`** реализует торговую логику.

#### 📊 Какие индикаторы используются

| Индикатор | Стандартные настройки | Зачем нужен |
|-----------|----------------------|-------------|
| **MACD** (12, 26, 9) | fast=12, slow=26, signal=9 | Показывает направление и силу тренда |
| **RSI** (14) | period=14 | Показывает, перекуплена или перепродана акция |
| **SMA200** | period=200 | Трендовый фильтр: цена выше SMA200 = тренд вверх |

#### 🚦 Как принимаются решения (логика сигналов)

**Режим OR (лучший — нашёл при оптимизации):**
```
КУПИТЬ  = (MACD пересёк сигнальную линию СНИЗУ ВВЕРХ ИЛИ RSI < порога_buy) И цена выше SMA200
ПРОДАТЬ = (MACD пересёк сигнальную линию СВЕРХУ ВНИЗ ИЛИ RSI > порога_sell) И цена ниже SMA200
```

То есть: покупаем, когда MACD даёт сигнал ИЛИ RSI говорит "перепроданность", но только если общий тренд восходящий (цена выше SMA200).

**Режим AND (строже):**
```
КУПИТЬ  = MACD пересёк вверх И RSI < порога И цена выше SMA200
ПРОДАТЬ = MACD пересёк вниз И RSI > порога И цена ниже SMA200
```

Если трендовый фильтр отключён (`use_trend_filter=False`) — тренд всегда считается "разрешённым".

#### 🛑 Стоп-лосс и Тейк-профит (опционально)

Можно задать при создании стратегии:
- `stop_loss_pct = 1.5` → если цена упала на 1.5% от цены входа — продаём
- `take_profit_pct = 4.0` → если цена выросла на 4% от цены входа — продаём

Если поставить 0 — защита отключена (как в лучшем найденном варианте).

#### 🔄 Методы класса

| Метод | Что делает |
|-------|-----------|
| `add_indicators()` | Добавляет в DataFrame колонки macd, macd_signal, macd_diff, rsi, sma200 |
| `generate_signals()` | Рассчитывает индикаторы и ставит сигнал BUY / SELL / HOLD |
| `apply_sl_tp()` | Накладывает стоп-лосс и тейк-профит поверх сигналов |
| `run_backtest()` | Полный бэктест из CSV: сигналы → SL/TP → колонки entries/exits → сохранение |
| `fetch_latest_candles()` | Скачивает последние ~250 свечей с MOEX |
| `get_current_signal()` | Возвращает словарь с текущим сигналом и значениями индикаторов |
| `run_realtime()` | Бесконечный цикл: проверяет сигнал и печатает в консоль |

#### 💾 Колонки для VectorBT

`run_backtest()` создаёт в конце две логические колонки:
- **`entries`** = True на свечах с сигналом BUY (вход в позицию)
- **`exits`** = True на свечах с сигналом SELL (выход из позиции)

Результат сохраняется в CSV-файл.

### 4. `optimize.py` — Подбор лучших параметров

**Задача:** перебрать 19 комбинаций параметров RSI и SL/TP, найти те, что дают лучшие показатели.

**Целевые метрики:**
- Sharpe Ratio >= 1.0 (отношение доходности к риску)
- Общая доходность > 25%

**Как работает:**
1. Загружает данные `data/sber_2022-01-03_2025-06-30.csv`
2. Для каждой комбинации (rsi_buy, rsi_sell, sl%, tp%) считает сигналы
3. Применяет SL/TP, если они заданы
4. Запускает VectorBT, собирает метрики
5. Выводит таблицу, отсортированную по Sharpe Ratio
6. Отдельно показывает лучшие комбинации (Sharpe >= 0.9, Return > 20%)

**Метрики по каждой комбинации:**
- `Return%` — общая доходность
- `Sharpe` — Sharpe Ratio
- `DD%` — максимальная просадка
- `Trades` — количество сделок
- `WinRate%` — процент прибыльных сделок

**Пример набора параметров:**
```python
(35, 65, 2.0, 5.0)   # RSI(35/65), SL=2%, TP=5%
(30, 70, 0,   0)     # RSI(30/70), без SL/TP — ЭТОТ ПОБЕДИЛ
```

---

## 🏆 Лучшие найденные параметры

Тестировали на данных **с 3 января 2022 по 30 июня 2025**.

| Настройки | Доходность | Sharpe | Просадка |
|-----------|-----------|--------|----------|
| **RSI(30/70), OR-логика, SMA200, без SL/TP** | **103.4%** | **1.78** | **17.8%** |
| RSI(35/65), OR-логика, SMA200, SL=1.5%, TP=4% | 60.3% | 1.56 | 18.9% |

**Лучший вариант:** покупать, когда RSI падает ниже 30 (и цена выше SMA200), продавать, когда RSI поднимается выше 70 (и цена ниже SMA200). Без стоп-лосса и тейк-профита.

## 🚀 Как запустить

### 1. Установить библиотеки
```bash
pip install pandas requests ta vectorbt
```

### 2. Скачать данные
Открыть `main.py`, установить:
```python
MODE = "download"
```
Запустить:
```bash
python main.py
```
Будет скачано ~50 000+ свечей (с 2000 года по сегодня). Один раз — и готово.

### 3. Запустить бэктест
В `main.py`:
```python
MODE = "backtest"
DATE_FROM = "2022-01-03"
DATE_TO = "2025-06-30"
CASH = 100000
FEES = 0.0005
```
Запустить:
```bash
python main.py
```
Вы увидите: доходность, Sharpe Ratio, максимальную просадку, количество сделок.

### 4. Подобрать параметры
```bash
python optimize.py
```
(Или установить `MODE = "optimize"` в `main.py`)

### 5. Запустить в реальном времени
В `main.py`:
```python
MODE = "realtime"
INTERVAL_SECONDS = 3600  # проверять каждый час
```
Запустить:
```bash
python main.py
```

## 📉 Формат CSV с сигналами

После бэктеста создаётся файл `data/signals_<дата>_<дата>.csv` с такими колонками:

```
datetime,open,high,low,close,volume,macd,macd_signal,macd_diff,rsi,sma200,signal,entries,exits
2022-01-03 10:00:00,152.5,153.2,151.8,152.1,...,45.2,150.0,HOLD,False,False
2022-01-03 11:00:00,152.1,153.0,151.5,152.8,...,48.5,150.1,BUY,True,False
```

- **signal** — BUY (купить), SELL (продать), HOLD (держать)
- **entries** = True на свечах с сигналом BUY (для VectorBT)
- **exits** = True на свечах с сигналом SELL (для VectorBT)

## 💡 Ключевые особенности проекта

1. **Бесплатные данные** — MOEX отдаёт свечи без API-ключа
2. **OR-логика** — сигнал срабатывает по любому из двух индикаторов (гибче)
3. **Трендовый фильтр SMA200** — не торгует против тренда
4. **Пагинация при скачивании** — загружает все данные частями, не теряя ничего
5. **Вырезка периода** — можно тестировать на любом интервале без повторного скачивания
6. **Оптимизация с расширенными метриками** — кроме доходности и Sharpe считает просадку, число сделок и win-rate
7. **Код написан понятно** — комментарии на русском, объяснения к каждому блоку
